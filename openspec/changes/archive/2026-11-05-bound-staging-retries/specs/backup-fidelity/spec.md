# Spec Delta

## MODIFIED Requirements

### Requirement: 备份的发布仍以完整复制为前提

只有内容, 权限, 修改时间与全部可设置的扩展属性都落定之后, 备份才 SHALL 被更名为最终名. 任一必需步骤失败时 MUST NOT 留下最终名, 原对象 MUST 保持原样. 除暂存根名被占用的有界重试 (由 `backup-lifecycle` 约束) 外, 复制内容期间的错误 (读取源, 填充子项, 应用元数据或同步; 包括嵌套子项创建时的 `AlreadyExists`) MUST 收敛为该条目的失败, MUST NOT 重试, MUST NOT 发布最终名, 原对象 MUST 保持原样.

#### Scenario: 元数据阶段失败

- **WHEN** 内容已复制但设置权限, 修改时间或扩展属性时发生必需步骤失败
- **THEN** 不产生最终名的备份, 本次创建的暂存对象被清理 (尽力而为), 原对象未被删除或修改

#### Scenario: 嵌套复制冲突收敛为条目失败

- **WHEN** 递归复制目录时某个子项的创建操作返回 `AlreadyExists`
- **THEN** 该条目报告失败且不再重试, 不产生最终名的备份, 本次暂存对象被清理 (尽力而为), 原对象保持原样
