# Spec Delta

## ADDED Requirements

### Requirement: 自愈备份前复核目标仍是本工具链接

在 `LinkedWrong` 自愈路径上, 写入自愈备份之前 MUST 重新 lstat 目标并复核: 目标仍是符号链接, 且其链接文本解析并规范化后仍落在仓库根内. 不满足时 MUST 使该条目失败, MUST NOT 写自愈备份, MUST NOT 删除或替换目标, MUST NOT 建立链接. 说明 MUST 指出"判定之后目标已被替换为非本工具链接或内容", 并提示重新运行. 复核 MUST 使用与 `classify` 和 `undo` 相同的 `link_destination` 与已规范化的仓库根.

#### Scenario: 目标被替换成普通文件

- **WHEN** 判定时目标是本工具的错误链接, 备份前被外部替换成普通文件
- **THEN** 该条目报告 `fail`, 普通文件保持原样, 不出现自愈备份, 不建立链接

#### Scenario: 目标被替换成仓库外链接

- **WHEN** 判定时目标是本工具的错误链接, 备份前被替换成指向仓库外的链接
- **THEN** 该条目报告 `fail`, 该链接保持原样, 不出现自愈备份, 不建立链接

#### Scenario: 目标在判定后被删除

- **WHEN** 判定时目标是本工具的错误链接, 备份前目标被外部删除
- **THEN** 该条目报告 `fail`, 目标保持不存在, 不出现自愈备份, 不建立链接, 说明指出判定已失效并提示重新运行

#### Scenario: 目标仍是仓库内的错误链接

- **WHEN** 判定时目标是本工具的错误链接, 备份前仍是符号链接且目标仍在仓库根内
- **THEN** 自愈继续, 旧链接被备份到 `.dotlink-heal.`, 目标成为指向当前 `source` 的链接, token 为 `replace`

## MODIFIED Requirements

### Requirement: 替换删除前必须原子复核身份

在删除被替换对象之前, `apply` MUST 以原子不覆盖的 rename 把目标移到同目录暂存名, 并复核暂存对象仍是备份实际复制的那个对象 (对象类型与文件身份一致). 身份基准 MUST 由备份写入时对复制起点的 lstat 快照给出, MUST NOT 使用备份开始前对目标另行取得的快照. 复核失败时 MUST 把暂存对象移回原路径 (若原路径为空), MUST NOT 删除它, 并报告失败; 失败说明 MUST 指出备份时的对象与删除时的对象不一致, MUST NOT 断言替换一定发生在备份之后. 复核成功后才可删除暂存对象并建立链接. `LinkedWrong` 自愈条目在备份开始前先走 "自愈备份前复核目标仍是本工具链接"; 该复核失败时, 本条目的备份与替换步骤不执行.

#### Scenario: 删除前目标被替换

- **WHEN** 备份完成后, 目标路径在删除前被外部替换成另一个符号链接
- **THEN** 暂存并复核发现身份不一致, 该链接被移回原路径并保留, 该条目报告失败, 备份不被删除

#### Scenario: 备份前目标被替换

- **WHEN** 备份复制开始前, `Foreign*` 条目的目标路径被外部替换成另一个文件
- **THEN** 备份保存替换后的文件, 删除前复核以该文件为身份基准并允许替换, 该行 token 为 `replace`

#### Scenario: 备份后目标被替换

- **WHEN** 备份完成后, 目标路径在删除前被外部替换成另一个文件
- **THEN** 暂存并复核发现备份时的对象与删除时的对象不一致, 替换物被移回原路径并保留, 该条目报告失败, 备份不被删除, 说明指出"备份时的对象与删除时的对象不一致"

#### Scenario: 正常替换

- **WHEN** 备份完成后目标路径未被替换
- **THEN** 目标被原子移入暂存名, 身份复核通过, 暂存对象被删除, 新链接建立, 该行 token 为 `replace`

#### Scenario: 目标被替换成目录

- **WHEN** 备份完成后目标路径在删除前被外部替换成目录
- **THEN** 目录被移回原路径并保留, 该条目报告失败, 不删除未备份内容
