# Spec Delta

## ADDED Requirements

### Requirement: 递归遍历不跟随被替换的目录项

备份复制与复制失败清理 MUST 使用 fd 相对的递归遍历, 每个子项 MUST 以不跟随符号链接的方式判定与打开. 若某个目录项在判定为目录之后, 打开或递归之前被替换为符号链接, 系统 MUST 使该条目失败或按符号链接处理, MUST NOT 跟随该链接复制或删除链接目标的内容. 符号链接本身仍按链接文本复制, MUST NOT 跟随. 原对象在该失败下 MUST 保持原样.

#### Scenario: 目录项被替换为外部符号链接

- **WHEN** 备份复制目录时, 某个子目录在判定之后被替换为指向仓库外的符号链接
- **THEN** 复制使该条目失败, 不读取或复制链接目标的内容, 不发布最终备份名, 原目录与链接目标保持原样

#### Scenario: 文件被替换为符号链接

- **WHEN** 复制普通文件时该子项在判定之后被替换为符号链接
- **THEN** 复制不跟随链接读取目标, 该条目失败或按链接本身处理, 链接目标内容不变

#### Scenario: 正常符号链接

- **WHEN** 目录中静态存在一个指向其他位置的符号链接
- **THEN** 备份仍只复制链接文本本身, 不跟随其目标
