# Spec Delta

## ADDED Requirements

### Requirement: 目录删除不跟随被替换的目录项

目录替换的递归删除 MUST 使用 fd 相对遍历与不跟随符号链接的删除原语. 若某个子目录在判定之后被替换为符号链接, 删除 MUST NOT 进入或删除链接目标的内容; 该路径 MUST 按链接本身处理或使删除失败, 并保留尚未删除的内容. 挂载边界检查, 暂存目录回滚, 失败报告与 token MUST 保持既有语义.

#### Scenario: 暂存子目录被替换为符号链接

- **WHEN** 删除暂存目录时, 某个子目录在判定之后被替换为指向仓库外的符号链接
- **THEN** 删除不进入链接目标, 链接目标内容保持不变, 该条目报告 `fail` 或按链接本身删除, 不建立链接

#### Scenario: 静态符号链接

- **WHEN** 暂存目录中静态存在一个符号链接
- **THEN** 删除只移除链接本身, 不删除其目标内容
