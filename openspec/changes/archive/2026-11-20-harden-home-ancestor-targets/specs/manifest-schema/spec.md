# Spec Delta

## ADDED Requirements

### Requirement: 清单校验 V-9c: 主目录的祖先也是受保护落点

`target` 规范化后是 `HOME` 的祖先时 MUST 整体拒绝, 退出码 2 且零改动. 判别 MUST 同时覆盖 `HOME` 的书写形态与解析末段符号链接后的物理形态. 以 `~` 简写书写, 按路径组件词法折叠后经 `..` 离开主目录的落点 MUST 一并拒绝; 该词法判定 MUST NOT 解析祖先符号链接, 因此指向主目录外部的符号链接子目录不因本条被拒. `HOME` 不可用时该比较不适用, 清单 MUST NOT 因此被拒. 落点存在时 MUST 按文件系统身份判等, 取不到身份时退回规范化字符串比较. 说明 MUST 指出条目下标与书写形态.

#### Scenario: 主目录的父目录落点

- **WHEN** 仓库不在 `HOME` 之下, 某条目写 `target = "~/.."` (或等价的 `HOME` 父目录绝对路径)
- **THEN** 四条命令都以退出码 2 整体拒绝, 标准输出为空, 说明指出 `entry[0]` 与该书写形态, 且不创建链接或备份

#### Scenario: 经主目录上溯的子路径落点

- **WHEN** 仓库不在 `HOME` 之下, 某条目写 `target = "~//../x"`
- **THEN** 整体拒绝, 退出码 2, 说明指出条目下标与书写形态, 而不是把它当作主目录之下的普通目标

#### Scenario: 主目录物理形态的祖先

- **WHEN** `HOME` 本身是符号链接, 某条目把 `target` 写成其物理形态的祖先目录 (例如 `HOME=/home/u` 指向 `/mnt/u` 时的 `/mnt`)
- **THEN** 整体拒绝, 退出码 2, 说明指出不能以主目录的祖先为落点

#### Scenario: 祖先目录的大小写别名

- **WHEN** 在大小写不敏感的文件系统上, 某条目把 `target` 写成 `HOME` 某个祖先目录的大小写变体, 二者文件系统身份相同
- **THEN** 整体拒绝, 退出码 2, 说明指出不能以主目录的祖先为落点, 而不是当作普通目录备份后替换

#### Scenario: 合法的下级与绝对落点不受影响

- **WHEN** 某条目写 `target = "~/sub"` 或 `target = "/etc/hosts"`
- **THEN** 清单被接受, 命令正常执行, 不会被 V-9c 误伤

#### Scenario: HOME 缺失时绝对落点不被误拒

- **WHEN** `HOME` 未设置, 清单中的目标全部是绝对路径且不是任何可判定主目录的祖先
- **THEN** 清单被接受, 该比较不适用不会使校验失败
