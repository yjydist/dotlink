# Spec Delta

## MODIFIED Requirements

### Requirement: 替换删除前必须原子复核身份

在删除被替换对象之前, `apply` MUST 以原子不覆盖的 rename 把目标移到同目录暂存名, 并复核暂存对象仍是备份实际复制的那个对象 (对象类型与文件身份一致). 身份基准 MUST 由备份写入时对复制起点的 lstat 快照给出, MUST NOT 使用备份开始前对目标另行取得的快照. 复核失败时 MUST 把暂存对象移回原路径 (若原路径为空), MUST NOT 删除它, 并报告失败; 失败说明 MUST 指出备份时的对象与删除时的对象不一致, MUST NOT 断言替换一定发生在备份之后. 复核成功后才可删除暂存对象并建立链接.

#### Scenario: 删除前目标被替换

- **WHEN** 备份完成后, 目标路径在删除前被外部替换成另一个符号链接
- **THEN** 暂存并复核发现身份不一致, 该链接被移回原路径并保留, 该条目报告失败, 备份不被删除

#### Scenario: 备份前目标被替换

- **WHEN** 备份复制开始前, 目标路径被外部替换成另一个文件
- **THEN** 备份保存替换后的文件, 删除前复核以该文件为身份基准并允许替换, 该行 token 为 `replace`

#### Scenario: 备份后目标被替换

- **WHEN** 备份完成后, 目标路径在删除前被外部替换成另一个文件
- **THEN** 暂存并复核发现备份时的对象与删除时的对象不一致, 替换物被移回原路径并保留, 该条目报告失败, 备份不被删除, 说明指出"备份时的对象与删除时的对象不一致"

#### Scenario: 正常替换

- **WHEN** 备份完成后目标路径未被替换
- **THEN** 目标被原子移入暂存名, 身份复核通过, 暂存对象被删除, 新链接建立, 该行 token 为 `replace`

#### Scenario: 目标被替换成目录

- **WHEN** 备份完成后目标路径在删除前被外部替换成目录
- **THEN** 目录被移回原路径并保留, 该条目报告失败, 不删除未备份内容

## ADDED Requirements

### Requirement: 替换末段建链失败时恢复原对象

删除已复核的暂存对象后建立链接失败时, `apply` MUST 立即从本次刚发布的备份把原对象复制恢复到目标路径, 使目标路径重新拥有原内容. 恢复 MUST NOT 删除或消费备份; 备份 MUST 保留. 恢复成功时该条目仍 MUST 报告失败, 说明 MUST 指出原内容已从备份恢复且备份仍在. 恢复也失败时说明 MUST 同时给出备份路径与恢复失败原因, 使原内容仍可从备份找回. 恢复 MUST 完整处理文件, 目录与符号链接三种备份内容, 不得只恢复一部分.

#### Scenario: 建链失败后从备份恢复

- **WHEN** 备份完成, 暂存对象已删除, 建立链接失败 (例如 `ENOSPC` 或 `EIO`)
- **THEN** 目标路径重新出现与备份一致的原内容, 备份仍在原地, 该行 token 为 `fail`, 说明给出备份路径并指出原内容已恢复

#### Scenario: 恢复也失败

- **WHEN** 建立链接失败, 且从备份恢复到目标路径也失败 (例如目标被并发新建的内容占用)
- **THEN** 并发新建的内容保持原样, 该行 token 为 `fail`, 说明同时给出备份路径与恢复失败原因, 备份不被删除

#### Scenario: 目录原对象完整恢复

- **WHEN** 被替换对象是目录, 暂存对象删除后建立链接失败
- **THEN** 目标路径重新出现与备份一致的完整目录树, 该行 token 为 `fail`, 备份保留
