# Spec Delta

## MODIFIED Requirements

### Requirement: 恢复失败时链接原样保留以便重试

移除链接并恢复备份时, 系统 MUST 先把链接原子移到同目录暂存名, 再复制备份就位. 复制失败且原路径仍为空时 MUST 把链接移回, 使该条目可在下一次 `undo` 重试. 回滚冲突时 MUST 保留暂存链接并在说明中给出其完整路径, MUST NOT 为恢复原状而覆盖期间新建的内容.

移除暂存链接失败时 MUST 先尝试以原子不覆盖的 rename 把链接移回原路径, 使下一次 `undo` 可重试; 移回成功时 MUST 报告失败并说明链接已回到原路径. 移回失败时 MUST 保留暂存链接, MUST NOT 删除它, 并在说明中同时给出移除失败原因与暂存链接的完整路径.

恢复失败说明 MUST 给出所尝试的备份路径与失败原因. 恢复成功但清理暂存链接失败时 MUST NOT 静默: MUST 保留恢复出的内容, 在说明中给出残留暂存链接的完整路径, 并把该条目报告为失败.

#### Scenario: 备份不可读

- **WHEN** 备份文件不可读, 复制到暂存名失败
- **THEN** 链接回到原路径, 该行报告失败, 说明给出所尝试的备份路径与失败原因, 下次运行仍可重试

#### Scenario: 回滚时原路径被占用

- **WHEN** 恢复失败, 回滚前原路径已被新内容占用
- **THEN** 新内容保持原样, 链接留在暂存名, 说明同时给出恢复原因, 回滚原因与暂存路径

#### Scenario: 移除链接失败时先移回

- **WHEN** 暂存并复核通过后, 移除暂存链接失败, 且原路径仍为空
- **THEN** 链接被 rename 回原路径并保留, 该行报告失败, 下一次 `undo` 仍可重试

#### Scenario: 移除失败且移回失败

- **WHEN** 移除暂存链接失败, 且原路径已被新内容占用
- **THEN** 新内容保持原样, 链接留在暂存名, 说明同时给出移除失败原因与暂存链接的完整路径

#### Scenario: 恢复成功但清理暂存链接失败

- **WHEN** 备份已恢复到目标路径, 但清理暂存链接失败
- **THEN** 恢复出的内容保持原样, 该行报告失败, 说明给出残留暂存链接的完整路径

### Requirement: 撤销的 token 由状态与备份有无共同决定

`undo` 的 token MUST 按状态与"同目录是否存在完整命名的备份"取定, 与"是否允许移除"无关: 已是最新或指向错误且有备份 -> `restore`; 已是最新或指向错误且无备份 -> `undo`; 目标为空且有完整备份 -> `restore`; 目标为空且无完整备份 -> `ok`; 目标被别的链接, 文件或目录占用 -> `skip`; 源缺失 -> `missing`; 无法判定或执行失败 -> `fail`. 目标为空时的 `restore` MUST NOT 先移除任何对象, MUST 在恢复落位时拒绝覆盖期间新建的内容. `Absent` MUST NOT 归为 `skip`. 恢复后目标被恢复内容占用: 若恢复内容不是本工具创建的链接, 再次 `undo` MUST 报告 `skip`; 若恢复内容本身是仓库根内的链接, 再次 `undo` MUST 按同一归属规则报告 `restore`; 两种情形都 MUST NOT 改变目标内容, MUST NOT 删除备份.

#### Scenario: 无备份的撤销

- **WHEN** 目标路径是本工具的链接, 同目录没有备份
- **THEN** token 为 `undo`, 计入成功列

#### Scenario: 有备份的撤销

- **WHEN** 目标路径是本工具的链接, 同目录有一份完整备份
- **THEN** token 为 `restore`, 说明给出备份路径

#### Scenario: 未部署不得归为跳过

- **WHEN** 目标路径本就不存在, 且同目录没有完整备份
- **THEN** token 为 `ok`, 计入已是最新列

#### Scenario: 目标为空但有备份

- **WHEN** 目标路径本就不存在, 同目录有一份完整备份
- **THEN** token 为 `restore`, 备份内容被恢复到目标路径, 说明给出备份路径, 退出码按现有两条件判据给出

#### Scenario: 目标为空恢复后再次撤销

- **WHEN** 第一次 `undo` 在目标为空时恢复了备份, 恢复内容不是本工具创建的链接
- **THEN** 第二次 `undo` 报告 `skip`, 目标内容与备份保持不变, 退出码 1
