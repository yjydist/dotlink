# Spec Delta

## ADDED Requirements

### Requirement: 替换删除前必须原子复核身份

在删除被替换对象之前, `apply` MUST 以原子不覆盖的 rename 把目标移到同目录暂存名, 并复核暂存对象仍是备份时的同一对象 (对象类型与文件身份一致). 复核失败时 MUST 把暂存对象移回原路径 (若原路径为空), MUST NOT 删除它, 并报告失败. 复核成功后才可删除暂存对象并建立链接.

#### Scenario: 删除前目标被替换

- **WHEN** 备份完成后, 目标路径在删除前被外部替换成另一个文件
- **THEN** 暂存并复核发现身份不一致, 新文件被移回原路径并保留, 该条目报告失败, 备份不被删除

#### Scenario: 正常替换

- **WHEN** 备份完成后目标路径未被替换
- **THEN** 目标被原子移入暂存名, 身份复核通过, 暂存对象被删除, 新链接建立, 该行 token 为 `replace`

#### Scenario: 目标被替换成目录

- **WHEN** 备份完成后目标路径在删除前被外部替换成目录
- **THEN** 目录被移回原路径并保留, 该条目报告失败, 不删除未备份内容
