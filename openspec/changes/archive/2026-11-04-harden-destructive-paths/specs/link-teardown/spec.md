# Spec Delta

## MODIFIED Requirements

### Requirement: 动手前复核目标仍是符号链接

判定与动手之间目标路径可能被替换, 因此移除或恢复之前 MUST 以原子不覆盖的 rename 把目标移入同目录暂存名, 再复核暂存对象. 暂存对象不是符号链接时 MUST 把它移回原路径 (若原路径为空), MUST 保留该路径, MUST NOT 消费备份, 并在说明中指出"判定之后被替换". 复核 MUST 同时确认暂存符号链接的目标仍属于本工具 (等于本条目的 `source` 或落在仓库根内); 暂存链接的目标落在仓库外时 MUST NOT 删除, 而是移回原路径并报告失败. 恢复的前提是本次运行亲手移除了该路径上的符号链接.

#### Scenario: 链接被换成真实文件

- **WHEN** 判定时目标路径是本工具的链接, 执行前被替换成用户自己的文件, 且同目录有备份
- **THEN** 该文件被保留, 备份不被恢复, 该行报告失败或跳过并给出原因

#### Scenario: 动手前复核身份

- **WHEN** 撤销准备移除目标路径时发现它已不是符号链接
- **THEN** 拒绝移除, 保留该路径, 说明指出"判定之后被替换"

#### Scenario: 链接被换成仓库外链接

- **WHEN** 判定时目标路径是本工具的链接, 执行前被替换成指向仓库外的链接
- **THEN** 该链接被移回原路径并保留, 不被删除, 该行报告失败
