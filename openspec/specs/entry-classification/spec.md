# entry-classification Specification

## Purpose

定义条目的现状判定与动作映射: 系统如何把"解析后的条目 + 文件系统实况"归入九种互斥的当前状态, 并由此导出该条目应当执行的动作.

## Requirements

### Requirement: 当前状态互斥且穷尽

系统 MUST 为每个条目给出且仅给出一种当前状态: 源缺失, 未部署, 已是最新, 指向错误, 别人的链接, 目标被普通文件占用, 目标被目录占用, 目标被特殊文件占用, 无法判定. 该判定完全只读, MUST NOT 产生任何文件系统改动.

#### Scenario: 八种取值由不同实况取到

- **WHEN** 依次构造源缺失, 目标不存在, 目标是指向源的链接, 目标是指向仓库内其他路径的链接, 目标是指向仓库外的链接, 目标是普通文件, 目标是目录, 目标路径读不到
- **THEN** 每次都得到对应的那一种状态, 且八个结果互不相同

#### Scenario: 特殊文件是第九种取值

- **WHEN** 目标路径是 FIFO, socket 或设备文件
- **THEN** 状态为"目标被特殊文件占用", 与上述八种状态均不同

#### Scenario: 判定不写文件系统

- **WHEN** 只做判定 (预览与检查)
- **THEN** 目标路径, 父目录与备份目录均保持原样

### Requirement: 求值顺序: 环境故障先于确定事实

系统 MUST 分别对源路径与目标路径各取一次元数据. 任一侧失败且错误不是"找不到"时, 该条目 MUST 判为"无法判定", 说明给出底层错误与失败的那一侧; 该结论先于其他所有状态, 因为它表示"部分状态根本无法求值", 而不是"某个条件命中". 不得把这类失败读作"路径不存在".

#### Scenario: 源侧不可进入

- **WHEN** 源路径的祖先目录权限不足, 而目标路径一切正常
- **THEN** 该条目判为"无法判定", 说明指出失败在源侧

#### Scenario: 双侧同时故障

- **WHEN** 源侧与目标侧都返回非"找不到"的错误
- **THEN** 说明同时给出两侧的原因, 不只报其中一侧

#### Scenario: 找不到不是故障

- **WHEN** 源侧返回"找不到", 目标侧返回"找不到"
- **THEN** 分别判为"源缺失"与"未部署", 都不是"无法判定"

### Requirement: 求值顺序: 源缺失先于目标侧

源路径不存在, 且两侧都没有环境故障时, 该条目 MUST 判为"源缺失", 且该结论 MUST NOT 受目标侧确定事实影响. 源缺失时无论目标侧是普通文件, 目录还是符号链接, 都无法建立有意义的一致性, 继续判定会给出误导性的"已是最新"或"冲突". 若目标侧存在环境故障, 按"求值顺序: 环境故障先于确定事实"判为"无法判定".

#### Scenario: 源缺失且目标被占用

- **WHEN** 源不存在, 目标路径上是一个普通文件
- **THEN** 判为"源缺失", 而不是"目标被普通文件占用"

#### Scenario: 源缺失且目标不存在

- **WHEN** 源不存在, 目标路径也不存在
- **THEN** 判为"源缺失", 而不是"未部署"

### Requirement: 目标路径不存在时判为未部署

目标路径及其父目录都不存在时 MUST 判为"未部署". 该状态蕴含"可以安全地直接建立链接".

#### Scenario: 多层父目录缺失

- **WHEN** 目标路径的若干级父目录都不存在, 而源存在
- **THEN** 判为"未部署"

### Requirement: 必须使用不跟随链接的元数据

判定 MUST 使用不跟随符号链接的元数据读取 (即 lstat 语义). 使用会穿透到链接目标的读取会使"别人的链接", "指向错误"与"目标被普通文件占用"无法区分.

#### Scenario: 目标是指向普通文件的链接

- **WHEN** 目标路径是一个指向文件 A 的符号链接, 而条目期望文件 B
- **THEN** 判定基于"这是一个符号链接"这一事实, 而不是"目标路径上有一个普通文件"

### Requirement: 符号链接归属以仓库根为界

目标路径是符号链接时, 系统 MUST 以链接文本解析并规范化后的结果判定归属: 落在仓库根之内 (含等于仓库根) 且不等于本条目的源, 判为"指向错误" (本工具的链接, 但指向的不是本条目的源); 落在仓库根之外判为"别人的链接". 二者互斥且穷尽全部符号链接情形.

#### Scenario: 仓库内指错

- **WHEN** 目标路径上的链接指向仓库内的另一个文件, 而不是本条目的源
- **THEN** 判为"指向错误", 说明给出实际指向

#### Scenario: 仓库外

- **WHEN** 目标路径上的链接指向仓库之外的路径
- **THEN** 判为"别人的链接", 说明给出实际指向

#### Scenario: 恰好指向源

- **WHEN** 目标路径上的链接经规范化后等于源路径
- **THEN** 判为"已是最新"

### Requirement: 动作映射与 on_conflict 无关的四格

以下四种状态的动作 MUST NOT 依赖 `on_conflict`: 源缺失 -> 报告源缺失; 无法判定 -> 报告无法判定; 未部署 -> 创建链接; 已是最新 -> 不动作.

#### Scenario: 两种策略给出同一动作

- **WHEN** 同一条目分别取 `on_conflict = skip` 与 `replace_and_backup`, 其状态为"未部署"
- **THEN** 两次导出的动作都是"创建链接"

### Requirement: 动作映射与 on_conflict 相关的四格

五种冲突类状态中, "指向错误" MUST 固定导出"备份后替换", MUST NOT 读取 `on_conflict`: 该状态蕴含链接落在仓库根内, 属于本工具产物, 与 `undo` 的移除规则一致. "别人的链接", "目标被普通文件占用" 与 "目标被目录占用" MUST 按 `on_conflict` 二选一: `skip` 导出"拒绝冲突", `replace_and_backup` 导出"备份后替换". "目标被特殊文件占用" MUST 固定导出"拒绝冲突", MUST NOT 读取 `on_conflict`: 特殊文件无法复制, 因此不存在"先完整备份再替换"的合法路径.

#### Scenario: 指向错误在 skip 下仍被替换

- **WHEN** 状态为"指向错误", `on_conflict = skip`
- **THEN** 动作是"备份后替换", 该条目不被报告为拒绝冲突

#### Scenario: skip 策略保留占用物

- **WHEN** 状态为目标被普通文件占用, `on_conflict = skip`
- **THEN** 动作是"拒绝冲突", 该条目在本次运行中不触碰目标路径

#### Scenario: 允许覆盖

- **WHEN** 状态为目标被目录占用, `on_conflict = replace_and_backup`
- **THEN** 动作是"备份后替换"

#### Scenario: 特殊文件不论策略都拒绝覆盖

- **WHEN** 状态为目标被特殊文件占用, `on_conflict = replace_and_backup`
- **THEN** 动作是"拒绝冲突", 目标路径不被备份, 删除或覆盖

### Requirement: 目标谓词对特殊状态的计数基准

导出退出码时, 部署, 预览与检查的目标谓词 MUST 把"未部署"计为"该目标尚未成为正确链接"; "源缺失"与"无法判定" MUST NOT 计入上述谓词. 后两者的残留待办已由"无遗留待办"这一独立条件表达, 若谓词也计数, 两个条件会在同一批条目上重复生效. 撤销的目标谓词刻意相反 (要求目标路径上不存在本工具创建的链接), 对"未部署"的取值为真, 不适用本条的计数基准, 见 `cli-contract` 的"各命令的目标谓词".

#### Scenario: 只含源缺失的清单上撤销

- **WHEN** 清单的唯一条目源缺失, 执行撤销
- **THEN** 目标谓词不因该条目为假, 但退出码仍为 1, 因为它计入"失败"列

#### Scenario: 只含源缺失的清单上预览

- **WHEN** 清单的唯一条目源缺失, 执行预览
- **THEN** 目标谓词不因该条目为假, 但退出码仍为 1, 因为它计入"失败"列

#### Scenario: 未部署使部署谓词为假

- **WHEN** 清单的唯一条目未部署, 执行预览
- **THEN** 目标谓词为假, 退出码 1

### Requirement: 四条命令消费同一份判定结果 [FR-017]

预览, 检查, 部署与撤销 MUST 共享同一套状态判定, 使同一文件系统状态下四者结论一致. 一致性 MUST 由数据流保证 (四条路径消费同一次判定的返回值), 而不是由四处逻辑各自对齐.

#### Scenario: 同一状态下的结论一致

- **WHEN** 同一份清单在同一文件系统状态下分别执行四条命令
- **THEN** 每条命令对同一条目使用的状态相同, 差异只出现在动作与输出措辞上

#### Scenario: 撤销只读取状态

- **WHEN** 检查撤销实现是否再次判定链接归属
- **THEN** 不需要: 归属已由状态取值本身表达
